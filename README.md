# CLAWD Wisdom

Пиксельный котик CLAWD, который гуляет по экрану и рассказывает про [Claude Code](https://claude.com/claude-code) — инструмент для работы с кодом через искусственный интеллект.

## Что это и зачем

Котик показывает маленькие подсказки про Claude Code: полезные команды, приёмы работы и интересные факты — всего 30 штук. Так можно в лёгкой игровой форме запомнить, что умеет Claude Code, и заодно полюбоваться котиком.

## Как запустить

1. Откройте файл `index.html` — просто двойным кликом по нему.
2. Всё. Устанавливать ничего не нужно, интернет не требуется — страница работает сама по себе.

## Как пользоваться

- **Кликните мышкой** в любом месте — котик мяукнет, а рядом с местом клика появится подсказка.
- **Нажмите Пробел или Enter** — подсказка появится возле котика (несколько подряд встают ступенькой, чтобы не лезли друг на друга).
- Подсказки показываются по очереди в случайном порядке; одна и та же повторяется, только когда покажутся все 30.
- Одновременно на экране бывает **не больше трёх** подсказок, каждая живёт **20 секунд** и исчезает сама.
- В правом верхнем углу — счётчик: сколько подсказок уже открыто и сколько осталось в «мешке».

## Из чего состоит

- `index.html` — сама страница;
- `styles.css` — внешний вид;
- `js/data.js` — тексты 30 подсказок;
- `js/script.js` — поведение котика и подсказок.

Проект — простая страница без сервера, сборщиков и внешних зависимостей.
