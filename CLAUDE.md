# CLAWD Wisdom — правила проекта

Одиночная десктопная страница с интерактивным пиксельным маскотом-котиком,
который показывает подсказки про Claude Code. Открывается двойным кликом по
`index.html`, бэкенда нет.

## Структура
- В проекте четыре файла: `index.html`, `styles.css`, `js/script.js` и `js/data.js`.
- `js/data.js` — массив из 30 подсказок про Claude Code (подключается первым, отдаёт `window.CLAWD_TIPS`).
- Никаких npm, сборщиков, фреймворков и бэкенда.
- Все ресурсы самодостаточны: спрайт-лист генерируется в коде, внешних файлов нет.

## Ограничения
- Без внешних шрифтов и сетевых запросов (без CDN, без веб-шрифтов, без fetch).
- Без inline-стилей и inline-скриптов в HTML.

## Анимация
- Вся анимация — через `transform` внутри одного общего цикла
  `requestAnimationFrame`. Никаких `setInterval`/`setTimeout` для анимации.
- Частота смены кадров спрайт-листа регулируется внутри цикла по накопленному времени.

## JavaScript
- Классический скрипт с атрибутом `defer`, один namespace (`CLAWD`) на всё приложение.
- Комментарии на русском, поясняющие ключевые решения.

## Языки
- Строки интерфейса (счётчик и т.п.) — на английском.
- Тексты подсказок про Claude Code — на русском.
